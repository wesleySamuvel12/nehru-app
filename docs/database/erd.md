# Entity-Relationship Overview

The database models:
- Schools & Branches (Tenancy)
- Users, Roles, Permissions (RBAC)
- Students, Parents, Guardians (Demographics)
- Classes, Sections, Subjects, Timetables (Academics)
- Invoices, Payments, Fee Categories (Finance)
- Transports, Hostels, Library, Infirmary (Facilities)
