# Core API Endpoints

- `POST /api/v1/auth/login` - Authenticate user
- `GET /api/v1/students` - Query students
- `POST /api/v1/attendance` - Record attendance
- `GET /api/v1/timetable` - Retrieve schedules
- `GET /api/v1/fees` - Financial invoices and ledger
- `GET /api/v1/health-check` - Liveness and readiness probe
